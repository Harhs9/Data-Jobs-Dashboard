The dashboard belongs to the Data specific jobs present across the globe.

Source Dataset -> The dataset is sourced from the kaggle.

Power BI Implementations : 
1. Cleaning -> After importing the dataset from the kaggle the data has been cleaned and transformed to visualize the data into specific models.
2. Visualizations -> Used three Cards, one Map, and one Stacked Bar Chart.
3. Cards -> There are total of three cards available:
                * One is visualizing the total jobs counts available across the globe.
                * Second one is visualizing the average yearly salary based on the data jobs.
                * Third one is visualizing the hourly average salary.

4. Map -> Map is used to see the presence of the jobs. There are bubbles to showcase the present jobs available on specific country.
5. Stacked Bar Chart -> The Stacked Bar chart includes four of the jobs title and to know about a particular title you can analyze the chart by clicking on the bars present in the chart.
